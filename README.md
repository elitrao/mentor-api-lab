# Mentor API Lab

Интерфейс для тестирования внешнего API Mentor: проверка ключа, сотрудники, загрузка звонков и отчёты по категориям. Работает локально на Node.js и на Cloudflare Workers. Для локального запуска сторонние зависимости не нужны.

## Запуск

Нужен Node.js 22 или новее.

```sh
git clone https://github.com/elitrao/mentor-api-lab.git
cd mentor-api-lab
npm start
```

Откройте **http://127.0.0.1:4318/**. В Windows также можно запустить `Start.cmd`. Установка пакетов не требуется. Чтобы остановить сервер, нажмите `Ctrl+C`.

Другой порт можно задать переменной окружения `MENTOR_LAB_PORT`.

## Cloudflare Workers

В проект включены `wrangler.jsonc` и обработчик `worker.mjs`. Страница и API публикуются вместе; Node-сервер `server.mjs` используется только локально.

Для Cloudflare Workers Builds, подключённого к этому репозиторию:

- Корневая директория: корень репозитория.
- Build command: `npm run build` (можно оставить пустым — Wrangler также запускает сборку автоматически).
- Deploy command: `npm run deploy` или `npx wrangler deploy`.
- Не используйте `--assets .`: этот параметр указывает на весь репозиторий, включая `node_modules`.
- Имя Worker в Cloudflare должно совпадать с `name` в `wrangler.jsonc` (`mentor-api-lab`).

Для проверки и публикации с компьютера:

```sh
npm ci
npm run check:deploy
npm run deploy
```

Последняя команда требует входа в Cloudflare. `check:deploy` выполняет сборку без публикации. Для проверки в локальном окружении Workers: `npm run dev:worker`.

Сборка создаёт `dist` из пяти явно разрешённых файлов: `index.html`, `app.js`, `reports.js`, `style.css`, `favicon.svg`. Ни исходники сервера, ни зависимости, ни ключи не становятся статическими ресурсами. `assets.directory` указывает только на `dist`. Запросы `/api/request` обрабатываются Worker и передаются выбранному серверу Mentor.

При размещении в Cloudflare введённый ключ и аудио проходят через Worker владельца сайта. Ключи не встроены в сборку: каждый посетитель вводит собственный ключ. Ничего не нужно добавлять в переменные сборки. На размер загрузки также распространяется ограничение HTTP-запроса вашего тарифа Cloudflare, включая multipart-заголовки; для файлов у верхнего предела используйте локальный режим.

## Возможности

- Переключение между `test.mentor.iqgroup.ai` и `mentor.iqgroup.ai`.
- Проверка ключа, создание и получение списка сотрудников интеграции.
- Загрузка MP3, WAV, FLAC, AAC, OGG, Opus и AMR до 100 МБ.
- Необязательные название звонка и указание голоса в левом стереоканале.
- Создание отчётов по категориям с фильтрами периода, сотрудников, категорий и длительности.
- Получение списка отчётов и результата по ID, сортировка и пагинация.
- Автоматическая проверка готовности отчёта каждые 15 секунд до `success`, `failed` или ошибки запроса.
- Предпросмотр URL, заголовков и body; HTTP-статус, время, исходный JSON, история и экспорт ответа.

## Как пользоваться

1. Выберите окружение и вставьте ключ в поле на странице.
2. Нажмите «Проверить ключ». Для каждого окружения нужен действующий в нём ключ.
3. Загрузите список сотрудников либо создайте менеджера. Выберите его ID для загрузки записи.
4. Выберите файл и отправьте звонок. Загрузка может резервировать стоимость анализа на балансе компании.
5. Во вкладке «Отчёты» выберите автора из менеджеров интеграции и период звонков. После создания ID отчёта подставится автоматически.

`201` со статусом `pending` означает запуск построения отчёта, а не готовый результат. Автор отчёта не заменяет фильтр `accountIds`. В списке отчётов поля `start` и `end` относятся к дате создания отчёта, а не к периоду звонков.

JSON body показан целиком. Для multipart отображаются заголовки части, имя файла, MIME-тип, размер и фактический boundary после отправки. Бинарные байты заменены описанием. Ключ скрыт в предпросмотре и истории.

## Локальная обработка

В локальном режиме сервер слушает только `127.0.0.1`. Браузер отправляет запрос локальному серверу, который передаёт его выбранному серверу Mentor по HTTPS. В Cloudflare эту роль выполняет Worker. Допустимые адреса и операции заданы в коде; перенаправления не выполняются.

Ключ остаётся в памяти вкладки и запроса, не записывается в файлы, `localStorage` или логи. После обновления страницы его нужно ввести заново. Записи передаются потоком без сохранения на диск. История существует только в текущей вкладке, пока пользователь сам не скачает ответ.

Автоматических повторов создания сотрудника, загрузки звонка или запуска отчёта нет. При сетевом обрыве или `500` исход операции может быть неизвестен — проверьте кабинет перед повторной отправкой.

## Проверки

```sh
npm test
```

Тесты используют локальный имитатор ответов, не отправляют запросы в Mentor и не требуют ключа. Проверяются JSON, multipart, маршрутизация, фильтры отчётов, валидация и состав публикуемых ресурсов. Отдельные тесты проверяют обработчик Cloudflare Worker.
