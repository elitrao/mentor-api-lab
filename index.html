Отчёты по категориям

Создайте отчёт за период или получите готовый.

POST

Это дата создания отчёта, не период звонков внутри него.

Пустые фильтры не отправляются. Автор отчёта не ограничивает список сотрудников: для этого заполните ID сотрудников.

Создание возвращает report.id и статус pending. Проверки GET продолжаются до success или failed. Повторное создание автоматически не запускается.

REQUEST

Отправляемый запрос

Предпросмотр · ключ скрыт
Как передаётся body
JSON показан полностью. Для multipart показаны заголовки части и описание бинарного файла. Маркер boundary в примере условный; фактический boundary создаёт браузер. accountId, callName и stereoLeftSpeaker передаются в URL, а не в body.
