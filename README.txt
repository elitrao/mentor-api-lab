MENTOR API LAB — локальная страница

Нужен Node.js 22 или новее. В этой системе он уже установлен.

Запуск: откройте Start.cmd и перейдите по адресу http://127.0.0.1:4318
Остановка: Ctrl+C в окне сервера.
Или из этой папки выполните: node server.mjs

1. Выберите окружение (по умолчанию тестовое).
2. Вставьте API-ключ и нажмите «Проверить ключ».
3. Получите список сотрудников либо создайте нового.
4. Выберите файл и отправьте звонок.

Справа показаны запрос и ответ. JSON body отображается целиком.
Для multipart показаны реальный boundary после отправки, имя файла,
тип содержимого и размер. Вместо бинарных байтов выводится их описание.
accountId, callName и stereoLeftSpeaker — параметры URL, а не body.
В истории можно открыть предыдущий запрос и соответствующий ответ.

Ключ не включён в исходный код, не хранится на диске и не сохраняется
в localStorage. Его нужно вводить заново после обновления страницы.
MP3 передаётся потоком через локальный сервер без записи на диск.
Ключ передаётся только выбранному серверу Mentor, редиректы запрещены.
Локальный сервер слушает только 127.0.0.1. Публикации в интернет нет.

Операции: GET key/verify, GET account/list, POST account, POST call.
Отчёты: POST category-report/generate, GET category-report/list,
GET category-report/{reportId}. Откройте вкладку «Отчёты».
Для создания обязательны authorAccountId, periodStart и periodEnd.
Период звонков — YYYY-MM-DD. Необязательные фильтры: categoryIds,
accountIds, minDurationMilliseconds и maxDurationMilliseconds (мс).
Пустые фильтры не отправляются. Несколько ID вводятся через запятую
или пробел. В GET они передаются повторяющимися query-параметрами.
Автор должен принадлежать интеграции. Он не заменяет фильтр accountIds.
После создания report.id подставляется в форму получения результата.
При включённом автообновлении GET выполняется раз в 15 секунд до
success, failed или ошибки запроса. Опрос можно остановить кнопкой.
Смена окружения, ключа, параметров или вкладки останавливает опрос.
В списке start/end — даты создания отчёта, не период звонков.
Можно выбирать режим auto/manual, сортировку и страницы результата.
Результат показан таблицей, а исходный JSON доступен для скачивания.
Состояние 201/pending означает запуск, а не готовность отчёта.
Сотрудник создаётся без отправки email или SMS этим инструментом.
Загрузка звонка может резервировать стоимость анализа в Mentor.
Автоматических повторов нет. При 500 или сетевом обрыве результат
создания/загрузки может быть неизвестен — перед повтором проверьте кабинет.

Тесты без обращения к Mentor: node --test server.test.mjs
Дополнительный порт: переменная окружения MENTOR_LAB_PORT.
